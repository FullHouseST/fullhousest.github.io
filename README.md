# Full House Studio - Web Portal

Repositorio principal de page oficial para el estudio de desarrollo independiente **Full House Studio**. Este portal centraliza la información, galería y enlaces de las dos divisiones principales del estudio: **Calaka Studio** y **PlushCraft Studios**.

## Stack Tecnológico

Este proyecto está construido con herramientas modernas enfocadas en el rendimiento y la mantenibilidad:

* **Framework:** [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
* **Lenguaje:** [TypeScript](https://www.typescriptlang.org/)
* **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
* **Animaciones:** [Motion](https://motion.dev/)
* **Iconografía:** [Lucide React](https://lucide.dev/)
